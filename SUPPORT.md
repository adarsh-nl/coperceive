# Support Guide

Thank you for using Coperceive! Here is how to find help, report issues, and ask questions.

## Where to Ask Questions

- **Questions & Community**: Use [GitHub Discussions](https://github.com/adarsh-nl/coperceive/discussions) for general questions about cooperative driving datasets, usage questions, ideas, or workflow troubleshooting.
- **Bug Reports**: If you encounter an unexpected crash, visual glitch, or reproducible bug, search [existing issues](https://github.com/adarsh-nl/coperceive/issues) and file a bug report using our [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature Requests**: Propose enhancements or new capabilities using our [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.yml).
- **Dataset Requests**: If you want support for a new dataset layout or HPC storage path, submit a request using our [Dataset Request template](.github/ISSUE_TEMPLATE/dataset_request.yml).
- **Security Vulnerabilities**: Please review [SECURITY.md](SECURITY.md) and report security issues confidentially via [GitHub Security Advisories](https://github.com/adarsh-nl/coperceive/security/advisories/new).
