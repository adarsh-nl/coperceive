# Synthetic demo scene

`coperceive demo create <dir>` (or `coperceive.demo.create(path, seed=0)`) writes a
small cooperative scene for first-run demos. Everything is generated by
Coperceive's own code under Apache-2.0; it contains **no third-party assets and
no real dataset frames**.

## What it contains

A four-way junction with two CAV agents (`cav-a`, `cav-b`) and one roadside unit
(`rsu`). Ten actors move for 10 s at 10 Hz: four cars, a cyclist and five
pedestrians. Each agent has a ray-cast LiDAR (boxes and ground); both CAVs have a
front camera rendered with shaded boxes and correct pinhole intrinsics. Ground
truth boxes are written for every actor and agent, plus a noisy simulated
prediction set with a few misses.

The layout is the generic multi-view format from
[`docs/spec/generic-multiview.md`](../spec/generic-multiview.md):

```text
<dir>/
  raw/scene.yaml + agents/<id>/{poses.csv,boxes.csv,lidar, camera}
  scenes/demo-junction/     # ingested schema-1 scene
  predictions/demo/         # run.json, boxes.parquet, predictions.jsonl, metrics
```

`create` runs the real `generic` adapter and ingests the scene, then scores the
simulated predictions with the existing evaluator. The score is a demo
self-check, not a model result and must not be presented as one. The point-cloud
files are float32 `.bin` (x, y, z, intensity); camera images are PNG.

## Budget

The generated tree is synthetic and must stay under **15 MB**. Generation time
and size are reported by the CLI; both are deterministic for a given seed.
