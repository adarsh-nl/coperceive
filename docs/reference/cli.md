# CLI reference

Generated by `scripts/docs/render_cli.py` from `ArgumentParser.format_help()`
on the commands registered in `coperceive/cli.py`. Do not edit this file by hand.
Regenerate it with `python scripts/docs/render_cli.py`.

There is no `coperceive import` command. A raw dataset is read with
`coperceive adapters ingest`. Model boxes are read with
`coperceive predictions import`.

## `coperceive`

```text
usage: coperceive [-h] [--version]
       {schema,capabilities,bundle,demo,serve,scene,maps,adapters,predictions,eval,model,remote,repro,robustness,download,convert,validate,export,dataset}
       ...

Cooperative multi-agent perception data tools.

positional arguments:
  {schema,capabilities,bundle,demo,serve,scene,maps,adapters,predictions,eval,model,remote,repro,robustness,download,convert,validate,export,dataset}
    schema              Print the on-disk schema version.
    capabilities        Print what this build supports, as JSON (for the desktop app).
    bundle              Export or open a shareable result bundle.
    demo                Create the synthetic demo scene.
    serve               Serve the local web app.
    scene               Copy a scene into a self-contained library folder.
    maps                Ingest a shared HD map and align it to scenes.
    adapters            List, check and run dataset adapters (ADR 0009).
    predictions         Import model predictions beside schema 1 scenes (ADR 0010).
    eval                Evaluate and report prediction runs (ADR 0010).
    model               Model plugins: list, inspect, check, run (ADR 0011).
    remote              Manage remote coperceive serve sessions on Slurm clusters.
    repro               Export or check a reproducibility card for a run.
    robustness          Robustness sweeps of one model over one scene split.
    download            Download a dataset.
    convert             Convert a raw dataset.
    validate            Write a JSON report and a Markdown report for schema 1 scenes.
    export              Export a scene to another format.
    dataset             Dataset catalog and operations.

options:
  -h, --help  show this help message and exit
  --version  show program's version number and exit
```

## `coperceive serve`

```text
usage: coperceive serve [-h] [--host HOST] [--port PORT] --root ROOT [--token TOKEN] [--token-file
       PATH] [--root-path ROOT_PATH] [--maps MAPS] [--predictions PREDICTIONS] [--static STATIC]
       [--media-root DIR] [--allow-origin ALLOW_ORIGIN] [--bundle-info PATH] [--remote-stream-argv
       REMOTE_STREAM_ARGV] [--remote-cache-dir REMOTE_CACHE_DIR] [--remote-cache-bytes
       REMOTE_CACHE_BYTES]

options:
  -h, --help  show this help message and exit
  --host HOST
  --port PORT
  --root ROOT  Directory the server is allowed to touch.
  --token TOKEN  Bearer token (deprecated for security; use COPERCEIVE_TOKEN or --token-
                        file).
  --token-file PATH  Path to a file containing the bearer token: a regular file you own (not a
                        symbolic link), mode 0600 or 0400.
  --root-path ROOT_PATH
                        URL prefix when the app sits behind a JupyterHub or similar proxy.
  --maps MAPS  Shared HD-map root. Defaults to ROOT/maps when that directory exists.
  --predictions PREDICTIONS
                        Predictions root. Defaults to ROOT/predictions when it holds a run.
  --static STATIC  Serve this web build (a vite build directory with index.html) instead of
                        the packaged one.
  --media-root DIR  Directory a scene's image links may resolve into, e.g. the dataset copy a
                        staged scene links its camera directories to. Repeatable.
  --allow-origin ALLOW_ORIGIN
                        Exact origin allowed for cross-origin requests.
  --bundle-info PATH  An opened result bundle's open.json. The scene summary then says whether
                        sensor frames are included, from the recipient's local copy, or omitted.
  --remote-stream-argv REMOTE_STREAM_ARGV
                        JSON argv of a `coperceive dataset stream` reached over SSH: --root is
                        then the local mirror of that cluster dataset (no Slurm job).
  --remote-cache-dir REMOTE_CACHE_DIR
                        Local disk cache for --remote-stream-argv.
  --remote-cache-bytes REMOTE_CACHE_BYTES
```

```text
  --model MODEL  One model of the plugin; default: default.
  --scenes SCENES  Directory of schema 1 scenes.
  --scene-ids SCENE_IDS
                        Comma-separated scene ids.
  --out OUT  Predictions root; sweep.json is written here.
  --run-id RUN_ID  Run id prefix of the cells; default sweep (each cell gets a stable

  --agents AGENTS  Comma-separated agent ids.
  --source SOURCE
  --raw-root RAW_ROOT
  --media-root MEDIA_ROOT
  --option K=V
  --frame-timeout FRAME_TIMEOUT
  --run-timeout RUN_TIMEOUT
  --no-cache
  --hash-inputs
  --work WORK  Work root; each cell uses <work>/<run_id>.

                        default: the eval spec's default config, recorded as 'default'.

  --slurm-python SLURM_PYTHON
                        Interpreter on the node; default this one.
  --slurm-partition SLURM_PARTITION
                        Slurm partition for --slurm.
  --slurm-logs SLURM_LOGS
                        Slurm log directory; default ~/logs.
  --slurm-results SLURM_RESULTS
                        Per-job results root; default ~/results.
  --slurm-scratch-template SLURM_SCRATCH_TEMPLATE
                        Scratch template for the job (default:
                        $COPERCEIVE_SLURM_SCRATCH_TEMPLATE).
```
