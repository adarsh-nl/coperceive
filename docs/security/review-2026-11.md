## Suggested fix
1. Do not ship `/eval` (and `/eval-result`) in release builds — register `eval_dispatcher` only under `test_seams::test_env_active()` / `#[cfg(debug_assertions)]`. Only callers are `scripts/desktop/e2e_mac.sh` and `smoke_test_linux.sh`.
2. If it must stay, forbid `window:"main"` (restrict dispatcher to `viewer`) and drop the `starts_with("http://127.0.0.1:")` CORS clause (`controller.rs:260`).
3. FOLD-12: move the secret/port writes inside the origin check (`main.rs:480`), replace the prefix test with exact `location.origin === origin`, and add an `on_navigation`/`on_page_load` guard pinning the viewer to `http://127.0.0.1:<sidecar port>`.
4. Validate `test_server_connection` input (`main.rs:2463`): reject `ssh_alias`/`host` starting with `-`, as `lab_share.rs:504-506` already does on import.
