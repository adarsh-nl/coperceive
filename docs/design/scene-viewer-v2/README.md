# Scene viewer styles

Design reference for Settings → Viewer → Style. The file `Scene Viewer v2.dc.html` is the export as handed over; it is not shipped code. It loads Geist from Google Fonts only in the mock. The desktop app bundles Geist and Geist Mono.

The three looks are Studio, Instrument and Cinema, plus a Cinema camera drift switch. The app keeps today's layout as Classic, the default, and applies the three looks as tokens on that same viewer.
